# ClassTrack – Smart College Attendance Management System

ClassTrack is a web-based College Attendance Management System designed to simplify and manage classroom attendance efficiently. It supports multiple attendance methods, including Manual Attendance, QR Code, OTP, Student Self Attendance, and Location-Based Attendance.

The system provides separate access for Teachers and Students, allowing teachers to manage attendance sessions and students to track their attendance records.

**Key Features:**
- Manual Attendance Management
- QR Code-Based Attendance
- OTP-Based Attendance
- Student Self Attendance
- Location-Based Verification
- Duplicate Attendance Prevention
- Subject-Wise Attendance Tracking
- Attendance History and Reports
- Attendance Correction Requests
- Role-Based Authentication

**Tech Stack:**
- Frontend: React.js, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL
- Authentication: JWT

**Project Goal:** To make college classroom attendance faster, smarter, more transparent, and easier to manage.
